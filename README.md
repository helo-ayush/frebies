# Frebies: landing page

Next.js 14 (App Router) · Tailwind CSS 3 · Framer Motion · Lucide icons

    npm install
    npm run dev      # http://localhost:3000

Structure: `app/` (layout, page, globals.css) and `components/` (`ui.tsx` primitives, `Navbar`, `Hero`, `Sections`).
Copy, prices ($0 / $9) and privacy claims are placeholders. Edit them in `components/`.
